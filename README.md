# BRCA_ancestry
Ancestry-differential gene co-expression in breast cancer: TCGA discovery, CPTAC replication, and a fixed-network comparison
This repository contains the analysis code for a study of how gene co-expression in breast cancer differs between European-ancestry and African-ancestry patients. Using RNA, methylation, and copy number data from 694 TCGA breast cancer patients, the pipeline tests whether ancestry acts on large co-expression modules or on individual gene pairs. It finds that the modules are preserved across ancestry while 3,368 individual gene-gene edges differ, and that these edge differences hold up under controls for tumor composition, molecular subtype, age, stage, and collection site. The edge directions are then tested for replication in an independent cohort (CPTAC) and compared against a fixed functional network (STRING).
